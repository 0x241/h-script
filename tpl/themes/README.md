# Пользовательские шаблоны

Каждая тема размещается в собственной подпапке `tpl/themes/<name>/`.
Значение `<name>` записывается администратором в поле пользователя `Шаблон`
(`uMode`).

Пример:

```text
tpl/themes/partner/header.twig
tpl/themes/partner/index/index.twig
tpl/themes/partner/cabinet/index.twig
```

В `uMode` для этой темы указывается только `partner`.

Не размещайте тему непосредственно в `tpl/partner/` и не используйте имена
системных каталогов `account`, `admin`, `balance`, `cabinet`, `index`,
`system` и других модулей. Каталог `tpl/themes/` отделяет пользовательские
overrides от штатных шаблонов H-Script.

Можно переопределять только необходимые файлы. Если файла нет внутри темы,
Twig загрузит его из основного каталога `tpl/`.

Имя темы должно содержать не более 10 букв, цифр, символов `_` или `-` и
начинаться с буквы или цифры.

После добавления новых Tailwind-классов пересоберите CSS:

```bash
npm run css:build
```
